# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Astro, requested by the user. Static output targeting GitHub Pages and a new koray.dev subdomain.

## Users

Developers comparing GitHub repositories and public activity. Confirmed by the user.

## Product Purpose

Rebuild raelsei/githup as a rich comparative GitHub analysis tool with a new name, brand, repository identity, description and README.

## Capabilities and Constraints

Use public GitHub API data. Preserve username lookup and repository exploration; add comparative analysis. Browser requests require no secret and must respect unauthenticated rate limits. Paginate repository collections and expose incomplete data. Public events are a bounded recent window, not a contribution calendar or complete work history. Static hosting cannot hold API credentials.

## Brand Commitments

Full rebrand requested. A 3D design is welcome. Working brand: Parallax, English interface, parallax.koray.dev target. User selected the Material Atlas design and code-led implementation, then explicitly requested a versus experience. Head-to-head comparison is the central product flow.

## Evidence on Hand

Original Vue source, MIT license and public GitHub API. No fabricated metrics, testimonials or user claims. Existing API fields include repository topics, primary language, stars, forks, license, archive and fork status, timestamps, size and issue/PR count.

## Product Principles

Compare observable public data with clear definitions. Make exploration useful without login. Keep 3D an optional, accessible view of real data. Retain clear coverage, loading, empty and error states.
